<objective>
Close the single diagnosed Phase 2 UAT gap (UAT test 4, severity major): UCI mate
scores are emitted as raw internal ply distances instead of signed full moves,
violating locked decision D-18 and the UCI spec (`score mate <y>` counts moves).
`send_info_depth(score=MATE-3)` currently prints `score mate 3`; per D-18 it must
print `score mate 2` (`y = ceil(plies / 2)`, sign preserved: negative when being
mated). Secondary half of D-18: evaluator centipawn output is not clamped below
the mate window (`MATE - MAX_PLY`), so a pathological eval value could be
misclassified as a mate score at the formatting seam.

Purpose: UCI-11 info-format correctness, GUI mate-distance display, and gauntlet
log comparability vs Stockfish (which reports `(plies + 1) // 2`).
Output: corrected `send_info_depth`, shared `MATE_THRESHOLD` constant, clamped
eval seam in quiescence, and regression tests locking the wire format.

Gap reason (from 02-UAT.md): send_info_depth emits raw ply distance (mate 3 for
MATE-3, mate -4 for -(MATE-4)) instead of signed ceil(plies/2) full moves;
evaluator cp also not clamped below the mate window.
</objective>
