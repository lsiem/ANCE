## Phase Goal

**As a** developer preparing Phase 5's NNUE swap-in, **I want to** turn Stockfish-labeled chess positions into a validated, exported `(768→256)×2→1` weights file via an offline PyTorch/MPS pipeline, **so that** Phase 5 can load real trained weights behind the untouched `evaluate()` seam and prove a measurable Elo gain over the handcrafted baseline.

> Note: see Plan 04-01 for the full discrepancy note on why this user-story framing is derived rather than quoted verbatim from ROADMAP.md.

> MVP vertical-slice note: this is the final thickening step per the planning brief — "the real wall-clock-capped overnight run." Every mechanism this run depends on was already proven correct on synthetic/tiny data by Plans 04-01 through 04-06's automated tests; this plan's own automated test only proves the CLI's wiring (`--smoke`), while the real run's *strength-bearing* output is explicitly a human-verified deliverable (per 04-VALIDATION.md's Manual-Only Verifications table), not an automated gate.

  <action>
Create `training/run_pipeline.py` as a CLI entrypoint (`argparse` + `def main(argv: list[str] | None = None) -> int`, plus `if __name__ == "__main__": raise SystemExit(main())`) with flags: `--smoke` (tiny synthetic run, no external downloads — mirrors Plan 04-06's Task 3 test but as a runnable script); `--lichess-zst PATH` (optional; if omitted, skip the bulk stream entirely rather than requiring the download to exist — degrade gracefully); `--fresh-n-games INT` (default `200`, fed to `training.label.position_source.generate_position_set`); `--depth INT` (default `None`; if unset, run `training.label.stockfish_labeler.run_depth_benchmark` first and pick the fastest candidate depth from `[10, 14, 18]` that still projects to fit the remaining fresh-labeling time budget); `--max-hours FLOAT` (default `10.0`, D-08's bounded overnight cap); `--out-dir PATH` (default `./training-run-output`).

Sequence the run: (1) call `training.train.preflight_mps_gate()` and print the returned device; (2) if `--lichess-zst` is given, stream-ingest via `training.data.lichess_ingest.iter_games`/`extract_samples` with an early-exit sample cap sized to the remaining time budget (never require processing an entire multi-GB dump, per Open Question #2); (3) fresh-label via `training.label.stockfish_labeler.run_and_record_labeling` at the resolved depth; (4) `training.data.merge.merge_and_dedup` the two streams; (5) `training.data.split.split_by_game` + `assert_no_fen_leakage`; (6) `training.data.kfit.fit_k_from_samples` on the train split, recording the fitted K via `training.run_manifest.record_event`; (7) `training.data.shards.build_shard` for both splits; (8) `training.train.run_training(..., k=fitted_k)` with a wall-clock deadline derived from `--max-hours` minus elapsed time so far — stop cleanly at the deadline, keeping the latest checkpoint (Pitfall 6's resumability, not a hard crash); (9) `training.export.export_checkpoint(...)` with `extra_meta` including the labeling command, dataset sample counts, and the current git SHA (via `subprocess.run(["git", "rev-parse", "HEAD"], capture_output=True, text=True, check=True).stdout.strip()`).

Each stage checks whether its output artifact already exists under `--out-dir` before recomputing it and skips if so (a simple `Path(artifact_path).exists()` check per stage, not a full content-hash cache — note in the docstring this simplicity is Claude's Discretion, satisfying Pitfall 6's "independently resumable" requirement without over-engineering it).

When `--smoke` is passed, short-circuit steps 2-3 entirely and instead generate ~40 synthetic FEN samples via `generate_position_set` with deterministic placeholder `cp`/`game_result` values (same technique as Plan 04-06's Task 3 capstone test), then continue through steps 4-9 with `epochs=1` — proving the wiring end to end in seconds.

Write `tests/training/test_run_pipeline_smoke.py::test_run_pipeline_smoke_flag_completes_fast`: call `training.run_pipeline.main(["--smoke", "--out-dir", str(tmp_path)])` directly (in-process, not via subprocess, for speed), assert it returns `0`, and assert `nnue_format.io.load_net(str(tmp_path / "net.safetensors"))` succeeds and its metadata's `arch_id` matches `nnue_format.schema.ARCH_ID`.
