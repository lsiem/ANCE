the Michniewski Simplified Evaluation Function (material + one PST per

default evaluator.

NNUE must beat. A richer handcrafted eval raises that bar deliberately
(user's explicit tradeoff, CONTEXT.md) — implement it in full, not a
material-only stand-in.

Output: `HandcraftedEval`, wired in as the default, with unit tests
spot-checking it against the published Simplified Evaluation Function
reference values, plus a reinforcement of the EVAL-01 swap-seam proof
now with two *real* evaluators.
</objective>
