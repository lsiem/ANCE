## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stdin `go <params>` | Untrusted numeric/flag tokens including spec-legal tokens (`wtime`/`nodes`/etc.) this phase does not act on |
| Worker thread <-> reader thread | Shared `stop_flag` and `rng` objects accessed from two threads |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-06 | Denial of Service | ance/uci/parser.py parse_go | high | mitigate | Every documented `go` sub-parameter is parsed into a typed field (parsed-and-ignored where unimplemented) rather than raising on unrecognized-but-spec-legal tokens — closes the exact crash pitfall RESEARCH.md flags for real GUIs that always send `wtime/btime` |
| T-01-07 | Denial of Service | ance/search/negamax.py negamax | medium | mitigate | `stop_flag` is polled every `NODE_POLL_INTERVAL` node visits and at every root move, bounding worst-case latency between `stop`/`quit` and search abort even though Phase 1 has no alpha-beta to bound node counts algorithmically |
| T-01-08 | Race Condition (Tampering) | ance/uci/loop.py stop_flag/rng shared state | low | accept | `threading.Event` is GIL-safe by design; `pos.copy()` is handed to the worker so the only genuinely shared mutable object is the stop flag itself, which is designed for cross-thread signaling |

</threat_model>
