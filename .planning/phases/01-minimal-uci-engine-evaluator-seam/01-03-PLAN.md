    guarantee this: a worker polling only every `NODE_POLL_INTERVAL`

    `global search_generation; search_generation += 1; my_generation = search_generation`
    **before** calling `_stop_active_worker()`, so any prior worker is
    numerically stale the instant a new `go` begins, independent of
    whether its `join()` succeeds. The worker-runner helper (see below)
    only calls `send_bestmove` when `my_generation == search_generation`
    still holds at the moment it is about to emit — a superseded worker's
    result is silently dropped (logged via `ance.debug.log`, not sent to
    stdout) instead of racing the new worker's output. The review's
    alternative suggestion — refusing to `clear()` until
    `not worker.is_alive()` — is deliberately NOT adopted as the
    correctness mechanism: blocking indefinitely on a stuck worker would
    either deadlock preemption or require an unbounded wait, violating
    D-13/D-00b's "never hangs" contract. `_stop_active_worker()` still
    escalates to error-severity logging on a join timeout for operator
    visibility, but proceeds to clear and cancel regardless, relying on
    `search_generation` for correctness.

    `handle_go(cmd)` computes
    `depth = cmd.depth or ance.search.negamax.DEFAULT_DEPTH`, and — when
    `cmd.movetime` is set — assigns the module-level
    `movetime_timer = threading.Timer(cmd.movetime / 1000, stop_flag.set)`
    (daemon, `.start()`ed immediately) rather than a purely local
    variable, so `_stop_active_worker()` can reach and cancel it from a
    later, unrelated preemption. This is the ONE pinned movetime
    mechanism: a single `search_root` call per worker, with the deadline
    fired by `threading.Timer` through the exact same `stop_flag` path as
    an external `stop` — never a manual polling loop wrapped around
    `search_root`. `handle_go` then spawns a daemon worker thread running

    `stop_flag.wait()` first if `cmd.infinite` (D-16), then in a `finally`

    `handle_go` updates the module-level `worker` reference to the new
