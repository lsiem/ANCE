## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stdin -> UCI parser | Every line on stdin is untrusted input from a GUI, arbiter, or test harness — the process must never crash or hang on it |
| pip install -> local environment | Third-party package code executes locally at install/import time |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Denial of Service | ance/uci/loop.py dispatch loop | medium | mitigate | Unrecognized leading tokens are skipped (continue), never raised past the dispatcher, from the very first version of the loop (D-11 applied from day one, not bolted on later) |
| T-01-02 | Denial of Service | ance/uci/loop.py reader thread | high | mitigate | Search work never runs on the reader thread (Pattern 3); `isready`/`quit` are answered from the reader thread regardless of worker state, so a stuck worker can never block the protocol stream |
| T-01-SC | Tampering | pip install of chess/pytest | high | mitigate | Blocking human checkpoint (Task 1) verifying package identity via pypi.org before install; both are `[SUS]` in the audit for data-availability reasons only, not real risk signals |

</threat_model>
